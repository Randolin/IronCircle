# Location Prompts

Splash-art prompts and Suno beds for the key locations. Image prompts follow the house splash format: the **style block** below is prepended verbatim to every prompt; each location supplies the scene, optional character anchors (descriptors lifted from the character notes so references match), lighting, and palette; every prompt ends with the same no-lettering line and the style-reference line. Music cues end with the locked spine from [[Themes]].

**Anchors.** Where a location prompt includes a character, the `═══ ANCHOR ═══` block names the reference images by slot and gives the character's one-line descriptor. Drop the anchor block for an empty version of the scene. Attire is whatever the character note says.

## Style block (prepend to every prompt)

```
A splash-page illustration in the style of a high-contrast noir comic: brush-and-pen ink linework over watercolor wash, fine dry-pen hatching modeling the forms, heavy spot blacks, visible paper tooth, a coarse analog grain overlay across the whole image, and slight chromatic fringing at the edges of the color plates.
```

## Closing lines (append to every prompt)

```
No lettering, no captions, no speech balloons, no watermark.

image4 is a STYLE reference for the image; do not use characters or the environment from this image
```
