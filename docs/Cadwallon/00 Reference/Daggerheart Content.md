# Daggerheart Content

Registry of the Daggerheart build options in play at this table — the valid values for `class`, `domains`, `community-archetype`, and `transformation` in the `pc` frontmatter ([[Schema]]). Rules text lives in the official books; mechanical conversions live in [[Conversion Notes]]. This note only enumerates what's *available* and flags what's still playtest.

> [!note] Core vs Void
> **Core** = the published Daggerheart core set; pairings are stable. **Void** = official Darrington Press playtest content from [The Void](https://www.daggerheart.com/thevoid/) — usable, but in active revision. Treat every Void domain pairing below as **provisional** until checked against the current v1.5 PDF.

## Domains (eleven)

- **Core (9):** Arcana, Blade, Bone, Codex, Grace, Midnight, Sage, Splendor, Valor
- **Void (2):** **Blood** — hemocraft; debuted with the Bloodhunter. **Dread** — fear and patron magic; the Warlock's signature.

## Communities

Daggerheart heritage is **ancestry + community**. At this table a PC's `community` links to the Cadwallon belonging (a fief, culture, or faction — per [[Conversion Notes]]), and `community-archetype` records the core Daggerheart community it maps onto.

- **Core archetypes:** Highborne, Loreborne, Orderborne, Ridgeborne, Seaborne, Slyborne, Underborne, Wanderborne, Wildborne
- **Void archetypes:** Duneborne, Freeborne, Frostborne, Hearthborne, Reborne, Warborne

## Transformations (Void)

Optional augmentations a GM may grant during play, or allow at creation. Record one in `transformation` on the `pc` note when it applies:
**Vampire, Werewolf, Reanimated, Shapeshifter, Ghost, Demigod.**

## Ancestries

Cadwallon uses its own roster — the eight canonical peoples plus the thirteen homebrew ancestries in [[Cadwallon/03 Cultures/Homebrew/Homebrew|Cultures Homebrew]]. A PC's `ancestry` links to those `culture` notes; mixed-ancestry characters list two. (The Void's own new ancestries — Aetheris, Earthkin, Emberkin, Skykin, Tidekin, Gnome — aren't part of this setting unless one is deliberately imported.)
