# Conversion Notes

Strategies for converting Cadwallon source material into Daggerheart mechanics. This is the working translation guide — log decisions here as they're made so future sessions stay consistent.

## Scope

This file covers *mechanical* conversion only:

- **Ancestries** — Cadwallon peoples → DH ancestry stats and features
- **Communities** — Cadwallon cultures, fiefs, or factions → DH communities
- **Adversaries** — Cadwallon NPCs/creatures → DH adversary stat blocks
- **Equipment** — Cadwallon weapons, armor, items → DH equipment cards
- **Magic** — Cadwallon spells/incantations → DH domain cards or environment effects

Flavor-level homebrew additions (new houses, renamed embassies, table-canon reinterpretations) do **not** belong here — those go in the relevant category's `Homebrew.md`.

## Working Principles

- **Daggerheart-as-default.** If a published DH ancestry/community/adversary already fits a Cadwallon concept reasonably well, use it. Reach for custom mechanics only when the fit is genuinely poor.
- **Match feel, not faithfulness.** Cadwallon's Confrontation system has very different math from DH. Don't try to preserve numeric balance — preserve the *experience* of being that thing or fighting that thing.
- **Domain alignment over school mapping.** When assigning DH domains to a Cadwallon magic concept, ask: what *kinds* of effects does this enable in fiction? That's the domain. Don't try to map Cadwallon's six magic schools to DH's nine domains 1:1.

## Decisions Log

Add entries as conversion decisions are made. Each entry should record: the Cadwallon concept, the DH mechanical home it landed in, and the reasoning (so future-us can revisit if it doesn't play well).
